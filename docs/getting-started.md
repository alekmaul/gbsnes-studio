# Getting Started

When you first open SNES Studio you will see the _New Project_ window.

{: .note }
> It's recommended to start with one of the sample templates, as they contain
> examples of lots of the functionality SNES Studio provides.

If you have an existing project you can open it from here by clicking _Open_ and navigating
to its `.gbsproj` file.

## New Project

Give your project a name to get started (don't worry, you can change this later) and choose
a project template:

- **Sample Project** - an 8-scene sample game (dialogue, menus, actors, a save point).
- **Sample Project (all genres)** - examples of top-down, platformer, point-and-click and
  shooter scenes.
- **Blank Project** - a completely blank canvas.

If you're new to SNES Studio, one of the sample templates is the best starting point - they
contain example scenes and scripts already set up so you can get a small idea of what's
possible. Click _Create Project_ and you'll be taken to the _Project Editor_.

<!-- TODO: add screenshot here - docs/assets/images/screenshots/project-editor.png
<img src="/gbsnes-studio/assets/images/screenshots/project-editor.png" alt="Project Editor" width="1258" />
-->

As soon as you see this screen you can click the Play button (&#9654;) in the top right,
which will build and run the project.

After playing the sample project, try clicking around the editor to see how it's set up.
Select one of the actors or triggers and edit its dialogue using the sidebar on the right,
then run the project again - you've just made your very own version of the game!

Don't worry if you break anything - you can always make a new project from a sample
template later.
