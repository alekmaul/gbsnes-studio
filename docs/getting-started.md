# Getting Started

When you first open GBSNES Studio you will see the _New Project_ window.

<img src="/gbsnes-studio/assets/images/screenshots/new-project.png" alt="New Project window" width="652" />

{: .note }
> It's recommended to start with the _Sample Project (SNES)_ template, as it contains
> examples of lots of the functionality GBSNES Studio provides.

If you have an existing project you can open it from here by clicking _Open_ and navigating
to its `.gbsproj` file.

## New Project

Give your project a name to get started (don't worry, you can change this later) and choose
a project template. If you're new to GBSNES Studio, the _Sample Project (SNES)_ template is
the best starting point - it contains a few example scenes and scripts already set up so you
can get a small idea of what's possible. Click _Create Project_ and you'll be taken to the
_Project Editor_.

<img src="/gbsnes-studio/assets/images/screenshots/project-editor.png" alt="Project Editor" width="1158" />

As soon as you see this screen you can click the Play button (&#9654;) in the top right,
which will build and run the project.

After playing the sample project, try clicking around the editor to see how it's set up.
Select one of the actors or triggers and edit its dialogue using the sidebar on the right,
then run the project again - you've just made your very own version of the game!

Don't worry if you break anything - you can always make a new project from the sample
template later.
