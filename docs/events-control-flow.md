# Control Flow

Branching, looping, and organizing a script.

**If / If Not** - branches on a single comparison.

**Switch** - branches to one of several cases based on a variable's value.

**Loop** - repeats a block of events forever, until a **Stop Script** or a branch out of the
loop.

**Label** / **Goto** - jumps to a named point elsewhere in the script.

**If Expression** - branches on a full expression rather than a single comparison.

**Loop While** - repeats a block of events while a full expression stays true.

**Wait** - pauses the script for a fixed amount of time.

**Stop Script** - ends the current script immediately.

**Call Custom Event** - runs a reusable, parameterized script defined elsewhere in the project.

**Group** - a purely organizational container for other events in the editor; has no effect on
its own.

**Comment** - an editor-only note; has no effect on the compiled script.
