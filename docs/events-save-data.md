# Save Data

Cartridge SRAM saves, with 3 independent save slots. Each save stores the player's position and
facing plus every variable.

**Save Data** - writes the current save scope to a slot.

**Load Data** - loads a slot back, restoring the player's position/facing and every variable.

**Clear Data** - erases a slot.

**If Data Saved** - branches on whether a slot has a save in it.
