# Engine Fields

Per-genre engine constants (e.g. a Platformer physics value, the Shoot 'Em Up scroll speed),
normally set once from Settings; these two events read or write one at runtime.

**Engine Field: Set** - writes a new value into an engine field, from a fixed value or a
variable.

**Engine Field: Store** - reads an engine field's current value into a variable.
