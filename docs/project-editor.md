# The Project Editor

The default view when you open a project is the _Game World_, where you build your game by
combining scenes, adding actors and triggers, then attaching scripting events to them.

## Editor tools

- **Select** - click a scene, actor or trigger to edit its properties in the sidebar.
- **Add** - place a new Actor, Trigger or Scene with your mouse.
- **Eraser** - remove collisions, actors and triggers (not scenes) by clicking or dragging.
  Undo with Ctrl/Cmd+Z if you remove something by mistake.
- **Collisions** - draw collision tiles onto a scene.

{: .note }
> GB Studio's Colorize tool doesn't apply here - SNES Studio backgrounds and sprites use a
> real palette extracted automatically from each PNG (see [Assets](assets.html)), so
> there's nothing to paint by hand.

## The Asset Viewer

The sidebar on the left lets you search and preview your game's assets - Sprites,
Backgrounds, UI Elements and Music. Click an asset to see a preview, or the edit button to
open it in its default external application.
